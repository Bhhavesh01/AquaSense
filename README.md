# AquaSense

## Smart Water Management System

## Description

AquaSense is a web-based application designed to help users monitor and manage their water consumption efficiently. It provides a user-friendly interface to track daily water usage across various activities like bathing, washing, cooking, and drinking, aiming to promote sustainable water habits.

## Features

*   **User Authentication:** Secure login and signup functionalities.
*   **Water Usage Tracking:** Record and monitor water consumption for different activities.
*   **Dashboard & Statistics:** Visualize daily water usage and related metrics.
*   **Eco-Score Calculation:** Potentially provides an eco-score based on water consumption (inferred from `ecoScoreEl` in `script.js`).
*   **Responsive Design:** (Inferred from `meta name="viewport"` in `index.html` and `style.css` usage).

## Technologies Used

*   **HTML5:** For structuring the web content.
*   **CSS3:** For styling and responsive design (using `style.css`).
*   **JavaScript:** For interactive functionalities and data handling (using `script.js`).
*   **Chart.js:** (Inferred from `cdn.jsdelivr.net/npm/chart.js` in `index.html`) For data visualization in the dashboard.
*   **Font Awesome:** (Inferred from `cdnjs.cloudflare.com/ajax/libs/font-awesome` in `index.html`) For icons.

## Installation

To set up AquaSense locally, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/Bhhavesh01/AquaSense.git
    ```

2.  **Navigate to the project directory:**

    ```bash
    cd AquaSense
    ```

3.  **Open `index.html`:**

    Simply open the `index.html` file in your web browser to run the application. No server-side setup is required as it's a client-side application.

## Usage

1.  **Sign Up/Login:** Create a new account or log in with existing credentials.
2.  **Record Usage:** Use the provided forms to input your daily water consumption for various activities.
3.  **View Dashboard:** Check the dashboard for an overview of your water usage patterns and statistics.
